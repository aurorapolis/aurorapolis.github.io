dear幹事

NEW公開中Webアプリ

幹事のあなたへ、ギルドを。

飲み会の幹事さんのための道具箱アプリです。お店さがし、参加者の名簿、会費の割り勘、集金の帳面、チラシとお誘い文まで。LINEとメモとExcelと電卓を行ったり来たりしなくていいように、ひとつにまとめました。

はじまりは、自分が幹事で苦労した経験です。毎年やってくる新人さんや、はじめて幹事を任された人が「幹事って案外おもしろいな」と思えるように作りました。会が終わってみんなの会費が集まると、いちばん下の「任務完了」ボタンがやっと押せるようになり、マスコットのもんじゃ君がねぎらってくれます。

  • 上から順に埋めていくだけで、会の段取りができあがります
  • 会費をいただいたら、名前の横に朱色の「済」。まだの人には「そっと一声」で、やわらかい催促の文をコピーできます
  • 「職場の会」「友だちの会」で、お誘い文の口調が切りかわります
  • お金は預かりません。参加者から幹事さんへ、PayPayなどで直接
  • 任務完了を重ねるごとに、称号が「見習い幹事」から「伝説のギルドマスター」まで上がっていきます
  • ログイン不要・インストール不要。入力した内容は、その端末の中だけに保存

HTML / CSS / JavaScript、独自ドメイン(dear-kanji.app)で公開

ふたやすみ

公開中Webアプリ

時刻を表示しない時計

画面に映るのは、空を渡っていく太陽と月だけ。時刻を読むのではなく、太陽の高さから「そろそろ昼だな」「もう日が傾いてきたな」と、感覚で時間を捉えるアプリです。

時間に追われたくないとき、通知から離れたいとき。時計を見ない時間をつくるための、静かな一枚として作りました。

  • 現在地と日付から、太陽と月の位置を天文計算で算出。季節や場所によって弧の高さも日の長さも変わります
  • 月は暦どおりに満ち欠け
  • 山の色は季節とともに移ろい、雲が流れ、夜には星が瞬いて、ときおり流れ星が走ります
  • 海 / 山 / 宇宙の3つの風景から選択
  • 通信は一切行わず、オフラインでも動作(PWA対応)

mattetene。

オーダーメイド受注Webアプリ

お店ごとに、つくり変えます。

撮りためた写真や動画を、1本の動画にまとめるアプリです。ボタンをひとつ押すだけで仕上がるので、動画編集の経験は要りません。

必要な機能だけを選べます。写真だけ。動画だけ。スローモーションや早送りなどは使わず、撮った順に並べたい、などなど。お店の使い方に合わせて、いらないものは外せます。

使いたいロゴ、使いたい音楽、好きなようにお伝えください。できあがった動画のフレームには、お店の名前を入れることもできます。

個人情報

写真や動画は、お店の端末から外に出ることはありません。どこかに送ることも、保存することもありません。

お客様の映像をあつかうお店でも、安心してお使いいただけます。インストールも不要で、ブラウザを開くだけで使えます。

おわたし例

  • トリミングサロン｜お預かり中のようすを、お迎えのときに
  • 体験施設｜その日のうちに、お客様へ
  • 幼稚園・保育園｜行事のようすを、ご家族へ
  • 自動車販売・自転車店｜納車まで、組み上がるまでのようすを
  • オーダー品の工房・メーカー｜できあがるまでを、お客様へ

ほかにも、入社式や表彰式など、行事の記録にも。
